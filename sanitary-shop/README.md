# Sanitary Shop: MERN store, billing and admin panel

**Customer:** browse and filter by category, brand and price · cart · cash on delivery · shipping by distance and weight · order tracking · ratings and reviews.
**Admin:** dashboard with charts · categories · add/edit/delete products with purchase rate, sale rate and margin · vendors · purchase entry (stock updates automatically) · vendor and customer payments · order management · low-stock alerts · SMS hook.

Stack: MongoDB, Express, React (Vite), Node. Charts: Recharts.
Folders: `backend/` (API) and `frontend/` (website). Deployment steps are in **DEPLOYMENT.md**.

Admin login: the `ADMIN_EMAIL` and `ADMIN_PASSWORD` you set in the backend environment (created on first start).
